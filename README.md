
# 💻 Programming Language Picker

A simple and interactive **Streamlit** web application that allows users to select their favorite programming language, learn about its common use cases, and rate it.

## ✨ Features

- 🎯 Select a programming language from a dropdown.
- 📚 Learn where the selected language is commonly used.
- ⭐ Rate your favorite language using a slider.
- 🎈 Fun balloon animation after submission.
- 🎨 Clean and beginner-friendly user interface.

## 🚀 Installation

### 1. Clone the repository

```bash
git clone https://github.com/yourusername/Programming-Language-Picker.git
```

### 2. Navigate to the project folder

```bash
cd Programming-Language-Picker
```

### 3. Install dependencies

```bash
pip install -r requirements.txt
```

or

```bash
pip install streamlit
```

---

## ▶️ Run the Application

```bash
streamlit run app.py
```

The app will open automatically in your browser.

## 📖 How It Works

1. Select a programming language.
2. Read a short description about its common uses.
3. Rate the language using the slider.
4. Click **Submit**.
5. Enjoy the 🎈 balloon animation!
